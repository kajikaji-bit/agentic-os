# Agentic OS

エージェントが継続的に活動し、人や外界と関わることを支える仕組み

## 構成要素

- 価値観: 何を大切にし、何を目指すかを持つ。
- 対話: 人や外界とやり取りする。
- 反応: 時間の経過や出来事に応じて、活動を起こす。
- 管理: 状況を把握し、目標・進捗・取り組みを調整する。
- 計画: 目標を仕事に分け、依存関係と着手順を決める。
- 行動: 決めた仕事を具体的に進める。
- 記憶: 経験や状況を引き継ぐ。

## 目標と進捗を管理する

仕事を任せるとき、共有しておきたいのは「何をするか」と「何のためにするか」。Agentic OS は、果たしたい使命、目指す状態、大切にする価値を Mission・Vision・Values として言葉にし、人とエージェントの判断の土台にする。

そこからマイルストーンと TODO へ具体化し、タスクの開始・終了に合わせて進捗を更新する。目標と今の状況を見ながら、次に取り組む仕事を一緒に選べる。

## 対話しながら仕事を進める

会話の隣に成果物を置き、気になる箇所へコメントする。その場で修正を確かめながら、意図と仕上がりを揃えていく。

このやり取りを支えるのが、作業場を整える Herdr と、差分を表示する Hunk。依頼やレビューコメントをエージェントが受け取り、不明な点を確かめて作業へ反映する。人が判断するための材料も、対話の中で共有する。

## 時間や変化をきっかけに動く

レビューが届いたとき、前のタスクが終わったとき、決めた時刻になったとき。仕事を進められる瞬間は、会話の外にもある。

タイマーと監視スクリプトがその変化を捉え、起きたことと対応の指示をエージェントへ届ける。繰り返す仕事にはループを組み合わせ、メンテナンスのような継続的な活動につなげる。

## 仕事を計画して実行する

大きな依頼を、着手と完了が分かる仕事に分ける。優先順位と依存関係を整理し、必要な準備から順に進める計画を作る。

実行を支える Agentic Runtime を同梱対象とし、各ステップでやること、必要な資料、完了条件をエージェントへ渡す。成果物・チェック・必要な承認を確認してから次へ進む。別のエージェントに任せる仕事は、専用の作業場を用意して、目的と完了条件をまとめて渡せる。

## 会話や資料を記憶する

前に話したことや、参考にした記事を、次の仕事でも使いたい。その続きを始めるために、会話と資料を手元に蓄積する。

Codex・Claude Code・Cursor の会話は、新しい発話を取り出して重複を避けながら保存する。ブログは本文・出典・画像を残し、必要なときに原文へ戻れるようにする。Wiki の索引や目標・進捗の記録も合わせて、後から参照できる形で引き継ぐ。
