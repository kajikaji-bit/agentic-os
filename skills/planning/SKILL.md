# Planning

## 手順

1. タスクを分解する
2. 依存を確認する
3. 順位付けする
4. 着手計画を作る

### 1. タスクを分解する

一つの目的だけが与えられた場合、目的の達成に必要で、それぞれ着手と完了を判定できる要素へ分ける。
計画対象の一覧がすでに与えられている場合、この手順を飛ばす。

### 2. 依存を確認する

完了に必要な前提を、別の対象が揃える関係を依存関係として確認する。
関係に現れない対象は、独立した対象とする。

### 3. 順位付けする

依存による着手可否は、順位付けの判断から除外する。
入力に明記された事実へ、判断基準を順に適用して一意に順位付けする。
明記されていない効果は補わない。

### 4. 着手計画を作る

優先順位を上から走査する。
各対象を置く直前に、未配置の依存元を同じ規則で置く。
