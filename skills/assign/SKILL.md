# Assign

## 手順

1. 依頼を用意する
2. ワークスペースを作成する
3. タスクを渡す

### 1. 依頼を用意する

`HERDR_ENV=1` と `herdr` が使えることを確認する。満たさなければ、その旨を伝えて終了する。

対象の作業ディレクトリ、タスクの目的、完了条件、参照する Issue や資料を揃える。エージェントの種類は指定に従い、指定がなければ依頼元と同じ種類を使う。

`herdr session list` と各候補の `workspace list`・`agent list`・`pane read` で、この会話があるセッションを特定する。以後のコマンドにはその `--session` を付ける。

### 2. ワークスペースを作成する

```bash
herdr --session <セッション名> workspace create --cwd <作業ディレクトリ> --label <タスク名> --no-focus
```

応答の `.result.workspace.workspace_id` と `.result.root_pane.pane_id` を控える。新しいワークスペースも指定した作業ディレクトリを共有する。ワークツリーによる分離が必要な依頼では、用意したワークツリーを指定する。

```bash
herdr --session <セッション名> agent start <エージェント名> --kind <種類> --pane <ペインID>
```

エージェント名は `[a-z][a-z0-9_-]{0,31}` に従い、生存中の名前と重複させない。起動に失敗したら依頼は送らず、作成済みのワークスペースと失敗内容を伝える。

### 3. タスクを渡す

相手はこの会話を知らないため、目的・完了条件・作業ディレクトリ・資料のパス・ユーザーが指定した制約を一つの依頼文にまとめる。

```bash
herdr --session <セッション名> agent prompt <エージェント名> '<依頼文>'
herdr --session <セッション名> agent get <エージェント名>
herdr --session <セッション名> agent read <エージェント名> --source recent-unwrapped --lines 60
```

依頼文はシェルで安全に引用して渡す。`--wait` は付けず、送信結果と画面から依頼が届いたことを確認する。未送信なら画面を確認して対処し、送信済みの依頼を重複して送らない。

セッション名、ワークスペース ID、ペイン ID、依頼したタスクを短く伝えて戻る。タスクの完了は待たず、作成したワークスペースとエージェントは残す。
